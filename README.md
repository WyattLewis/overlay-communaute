# 🎮 WL-Apps (bêta)

Ta **carte** (niveau, pièces, viewers), tes **notifications** et le **chat Twitch** de ta chaîne **par-dessus ton jeu**, pour toi seul : la fenêtre est **invisible pour OBS** et les captures d'écran, donc rien en double sur ton live.

## Installation

1. Télécharge **[WL-Apps-Setup.exe](https://github.com/WyattLewis/overlay-communaute/releases/latest/download/WL-Apps-Setup.exe)** (Windows 10 mai 2020 ou plus récent).
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur » (logiciel non signé) : **Informations complémentaires → Exécuter quand même**.
3. Sur le site de ta communauté : **Mes overlays → Logiciel pour PC → Copier mon code de connexion**, puis colle-le dans le logiciel.

## Utilisation

| Raccourci | Action |
|---|---|
| `Ctrl` + `Maj` + `O` | Mode édition : déplacer, redimensionner, régler la carte, les notifications et le chat |
| `Ctrl` + `Maj` + `H` | Masquer / afficher |

Le reste est dans l'icône près de l'horloge : invisible pour OBS, sons des notifications, choix de l'écran, lancement au démarrage de Windows, changement de code, mises à jour.

Mets ton jeu en **plein écran fenêtré** (ou « sans bordure ») : en plein écran exclusif, le jeu passe par-dessus.

Le logiciel ne touche jamais au jeu (aucune injection) : aucun risque avec les anti-triches.
